# Third-party code

The session event-tap foundation is adapted from
[mac-inputlock](https://github.com/choiyounggi/mac-inputlock) by Younggi Choi,
used under the MIT License.

Reference revision:
[`0cfea7c19fe3e9dd02dfb6be7187fac50058ad63`](https://github.com/choiyounggi/mac-inputlock/tree/0cfea7c19fe3e9dd02dfb6be7187fac50058ad63).
The adapted portions include the event-type list, event mask, session event-tap
setup and run-loop attachment. The original copyright notice and full MIT
license are retained in [LICENSE](LICENSE).

This project adds typed-code unlocking, optional local Keychain storage,
bounded and unlimited command-line modes, Secure Input/layout checks,
diagnostics, packaging and documentation. It does not bundle upstream binaries.
